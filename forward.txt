
An open-source, developer-first alternative to Figma Code Connect. This platform allows backend developers to map code endpoints and API documentation directly to an independent, open-source visual design canvas using a Bring-Your-Own-Database (BYOD) model backed by the Firebase Realtime Database.

---

## 🏗️ Architecture Overview

The system operates as a fully decentralized, three-part ecosystem connected by the user's private Firebase instance.

Use code with caution.[VS Code Extension] ──(Parses & Pushes Docs)──> [User's Realtime DB] <──(Live Socket Sync)──> [Custom Web Canvas App]
1. **The VS Code Extension:** Captures highlighted API routes, extracts payload structures, prompts for Canvas IDs, and pushes to Firebase. api version control history. the api's are documentated or displayed on the exact design to ease integration
2. **The Firebase Realtime Database:** Acts as the live data mesh, synchronizing data across client machines in milliseconds.
3. **The Custom Web Canvas:** A lightweight graphic space where layout blocks map natively to incoming API schemas and display real-time version history.

## 💻 2. VS Code Extension Stack (TypeScript + Vitest)

To achieve strict data modeling and maintain high-utility unit tests without cross-compilation layers, the extension uses native **TypeScript** paired with **Vitest**.

### System Configuration (`package.json`)
```json
"contributes": {
  "commands": [
    {
      "command": "forward.connectEndpoint",
      "title": "Connect API Route to Design Canvas"
    }
  ]
}
```

### Data Contracts (`src/types.ts`)
```typescript
export interface ApiPayload {
  endpoint: string;
  method: 'GET' | 'POST' | 'PUT' | 'DELETE';
  parameters: string[];
  version: string;
}

export interface DesignMapping {
  canvasNodeId: string;
  apiData: ApiPayload;
  updatedAt: string;
}
```

### Business Logic Unit Test (`src/parser.test.ts`)
```typescript
import { describe, it, expect } from 'vitest';
import { parseHighlightedCode } from './parser';

describe('API Route String Parser Verification', () => {
  it('should cleanly extract details from a standard Express route structure', () => {
    const mockCode = `app.post('/api/v1/login', (req, res) => {})`;
    const result = parseHighlightedCode(mockCode);

    expect(result.method).toBe('POST');
    expect(result.endpoint).toBe('/api/v1/login');
  });
});
```

## 🎨 3. Custom Web Canvas Framework

To escape the strict layouts, API limits, and iframe sandboxes found within Figma, build the user application canvas independently using standard web web technologies.

* **Core UI Pipeline:** Use **HTML5 Canvas** or interactively structured inline **SVG groups** to draw layouts, link wires, and draw app design rectangles.
* **State Sync Layer:** Initialize the frontend web app directly with the user’s self-provided Firebase dynamic runtime configuration block.
* **Component-to-API Panel:** Utilize full-width sliding drawer modules that pop open whenever a visual block is focused, drawing documentation tables straight out of the `canvas_nodes` JSON payload.

---

## 🚀 Key Advantages Over Figma

* **Decentralized Infrastructure:** Users possess total privacy over data channels by supplying their personal Firebase parameters.
* **Zero Sandbox Limits:** Eliminates layout structural rules or memory network socket boundaries present inside browser design plugins.
* **Live Update Callouts:** Employs real-time visual notification states on the canvas surface, updating frontend engineers with warning flags instantly whenever backend code contracts pivot.
