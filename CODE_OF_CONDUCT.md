# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good faith, and keep discussion focused on the
work. Harassment and personal attacks are not tolerated.

Report unacceptable behaviour privately to the maintainer, [@dsasante1](https://github.com/dsasante1),
through a GitHub private security advisory or by any private channel listed on their profile.
Reports are handled confidentially.
